# GUI·UI Publish

GUI팀이 배포한 화면을 UI팀의 플립북에 바로 반영하고, 화면이 언제 바뀌었는지 기록으로 남기는 Figma 플러그인의 배포 페이지입니다.

## 최신 버전 받기

**[GUIUIPublish.zip 받기](https://github.com/ynjoh9494/gui-ui-publish/releases/latest/download/GUIUIPublish.zip)**

항상 가장 최근 버전을 받는 링크입니다. 버전별 변경 내용은 [Releases](https://github.com/ynjoh9494/gui-ui-publish/releases)에서 볼 수 있습니다.

## 설치 (Figma 데스크톱 앱에서 한 번만)

1. zip 압축을 풀고, 지우지 않을 폴더에 둡니다(예: `문서\FigmaPlugins\GUIUIPublish`).
2. Figma 데스크톱 앱 메뉴에서 **Plugins → Development → Import plugin from manifest…** 를 누릅니다.
3. 압축을 푼 폴더 안의 `manifest.json`을 고릅니다.

실행은 **Plugins → Development → GUI·UI Publish** 에서 **GUI Publish**(GUI 담당) 또는 **UI Flipbook**(UI 담당)을 고릅니다.

## 사용법

zip 안의 `GUIUIPublish-Guide.html`을 더블클릭하면 브라우저에서 사용 안내가 열립니다. 용도, 전체 흐름, 초기 세팅, 기능별 사용법을 그림과 함께 정리했습니다. 플러그인 창 오른쪽 위의 파란 물음표 버튼을 누르면 튜토리얼도 볼 수 있습니다.

## 업데이트

새 버전 zip을 받아 처음 설치한 폴더에 덮어쓰고 플러그인을 다시 실행합니다. 다시 불러올 필요는 없습니다.
